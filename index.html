01 / Multilingual AI

LLM-Aug-MoE

A multilingual mixture-of-experts architecture that combines a compact base model with task-specific experts through cross-attention and selective layer freezing. It improved low-resource language performance by 28% while reducing compute cost by roughly 60%.

MULTIMODAL RESEARCH / 02TEXT+IMAGESee the whole picture.
02 / Vision + language

Vision Augmented LLMs

A joint text-image reasoning system combining CLIP ViT and StableLM through cross-attention, packaged with Docker and Hugging Face Hub for reproducible experimentation. The result is a repeatable multimodal experimentation stack rather than a notebook-only demo.
