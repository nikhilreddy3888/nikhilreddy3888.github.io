# Nikhil Reddy’s portfolio

A minimal static portfolio for GitHub Pages. Plain HTML and one shared stylesheet; no JavaScript, build step, or external fonts.

Preview locally:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Update `index.html` for the introduction, research, and experience; supplementary pages live in `about/`, `work/`, and `publications/`. Paper metadata, PDFs, and BibTeX files remain alongside each paper.
